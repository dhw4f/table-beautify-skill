# Table Beautify Skill

> 智能美化表格数据展示，让用户一眼抓住数据重点

## 简介

这是一个用于美化智能体回答中表格数据的skill。当回答中包含表格数据、对比数据、统计信息时，使用此skill可以显著提升数据展示效果，让用户更快理解和抓住重点。

## 核心特性

- ✨ **数据高亮** - 自动突出极值（最大、最小、异常值）
- 📊 **可视化增强** - 进度条、柱状图、颜色编码
- 📈 **智能排序** - 按重要性或数值自动排序
- 📋 **汇总统计** - 自动添加合计、平均值等汇总行
- 💡 **关键洞察** - 表格下方提供数据洞察总结
- 🎯 **图表建议** - 主动建议何时用图表替代表格

## 适用场景

| 场景 | 示例 |
|:-----|:-----|
| 销售数据展示 | 业绩排名、对比分析 |
| 系统监控 | CPU、内存、磁盘使用率 |
| 技术对比 | 框架、工具、产品规格对比 |
| 财务报告 | 收入、成本、利润数据 |
| 进度跟踪 | 项目任务、里程碑进度 |
| 统计分析 | 调查结果、用户数据分析 |

## 快速开始

### 1. 基础用法

当智能体的回答中需要展示表格数据时，参考 `SKILL.md` 中的指南进行美化。

### 2. 选择合适的格式

根据场景选择输出格式：

- **Markdown表格** - 适用于对话、文档、README
- **HTML表格** - 适用于网页、需要丰富样式
- **ASCII表格** - 适用于终端、命令行

### 3. 应用美化原则

核心原则（详见 `SKILL.md`）：
1. 数据高亮（极值标注）
2. 智能排序
3. 汇总统计
4. 格式一致性
5. 图表建议

## 示例

### 普通表格

```
| 名称 | 数值 |
|:-----|----:|
| A    | 100  |
| B    | 200  |
```

### 美化后的表格

```markdown
## 📊 数据对比

| 名称 | 数值 | 占比 | 状态 |
|:-----|----:|:---:|:----:|
| **B** | **200** | **66.7%** | 🏆 最佳 |
| A    | 100 | 33.3% | ✅ 正常 |
| **合计** | **300** | **100%** | - |

**关键洞察**：
- 🏆 B 的数值是 A 的 2 倍
- 📊 B 占总体的 66.7%
```
