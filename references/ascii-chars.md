# ASCII表格字符参考

## Box Drawing Characters

### 单线边框

```
┌─┬─┐  顶部
│ │ │  内容
├─┼─┤  分隔
│ │ │  内容
└─┴─┘  底部
```

**完整字符集**：

| 用途 | 字符 |
|:----|:-----|
| 左上角 | `┌` |
| 右上角 | `┐` |
| 左下角 | `└` |
| 右下角 | `┘` |
| T形向下 | `┬` |
| T形向上 | `┴` |
| T形向右 | `├` |
| T形向左 | `┤` |
| 十字 | `┼` |
| 横线 | `─` |
| 竖线 | `│` |

### 双线边框

```
╔═╦═╗
║ ║ ║
╠═╬═╣
║ ║ ║
╚═╩═╝
```

### 粗线边框

```
┏━┳━┓
┃ ┃ ┃
┣━╋━┫
┃ ┃ ┃
┗━┻━┛
```

### 数据状态

| 符号 | 含义 |
|:----:|:-----|
| ✓ | 通过/完成 |
| ✗ | 失败 |
| ★ | 优秀 |
| ☆ | 一般 |
| ▲ | 上升 |
| ▼ | 下降 |
| → | 稳定 |
| ⚠ | 警告 |
| ❌ | 错误 |

### 进度条

```
[████████░░] 80%
[██████░░░░] 60%
[████░░░░░░] 40%
```

**字符**：
- 完整方块：`█` (U+2588)
- 浅色方块：`░` (U+2591)
- 中等方块：`▒` (U+2592)
- 深色方块：`▓` (U+2593)

## 字符宽度说明

⚠️ **重要**：中文字符占2个字符宽度，英文字符占1个字符宽度。

计算列宽时：
- 中文字符数 × 2 = 实际显示宽度
- 英文字符数 × 1 = 实际显示宽度
- 表格总宽度 = 所有列宽之和 + 分隔符数量

**示例**：
```
"张三" = 2个中文字符 = 4宽度
"Zhang San" = 8个英文字符 = 8宽度
```
