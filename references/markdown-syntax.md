# Markdown表格语法参考

## 基本语法

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |
```

## 对齐方式

通过分隔符控制列对齐：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 数据   |   数据   |   数据 |
```

- `:---` 左对齐
- `:---:` 居中对齐
- `---:` 右对齐

**最佳实践**：
- 文本列：左对齐
- 数字列：右对齐（方便对比数值大小）
- 短标签列：居中对齐

## 格式化技巧

### 加粗重要数据

```markdown
| 名称 | 数值 |
|:-----|-----:|
| 普通 | 100  |
| **重要** | **200** |
```

### 使用emoji标记

```markdown
| 状态 | 说明 |
|:----:|:-----|
| ✅   | 完成 |
| ⚠️   | 警告 |
| ❌   | 失败 |
| 🔥   | 热门 |
```

### 代码格式

```markdown
| 函数 | 说明 |
|:-----|:-----|
| `func1()` | 第一个函数 |
| `func2()` | 第二个函数 |
```

## 复杂表格

### 合并单元格（不直接支持）

Markdown不原生支持合并单元格，但可以用以下技巧：

```markdown
| 类别 | 项目 | 数值 |
|:----:|:----|-----:|
| A    | X   | 100  |
| A    | Y   | 200  |
| A    | **小计** | **300** |
| B    | Z   | 150  |
```

### 长文本处理

对于长文本，使用 `<br>` 标签换行：

```markdown
| 描述 | 说明 |
|:-----|:-----|
| 第一点<br>第二点 | 详细说明 |
```

## 特殊字符处理

如果表格内容包含 `|` 字符，需要转义：

```markdown
| 符号 | 含义 |
|:----:|:-----|
| `\|` | 或   |
| `&`  | 和   |
```

## 可访问性建议

1. **使用表头**：第一行始终是表头
2. **避免纯颜色**：用emoji或文字补充颜色信息
3. **保持简洁**：单元格内容不要过长
4. **提供摘要**：表格后用文字总结关键发现
