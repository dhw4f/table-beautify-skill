# 数据可视化建议 - 表格 vs 图表

## 何时用表格 vs 图表

### 使用表格的场景 ✓

| 场景 | 原因 | 示例 |
|:-----|:-----|:-----|
| 需要精确数值 | 图表难以显示精确值 | 财务报表、参数对比 |
| 少量数据点（<5个） | 图表会显得空洞 | Top 3产品 |
| 多维度对比 | 表格能展示更多属性 | 产品规格对比 |
| 文本信息为主 | 图表不适合文本 | 任务清单、特性列表 |
| 需要排序和筛选 | 表格易于操作 | 数据列表 |

### 使用图表的场景 📊

| 场景 | 推荐图表 | 原因 |
|:-----|:---------|:-----|
| 显示趋势变化 | 折线图 | 清晰展示时间维度变化 |
| 数据点较多（>10个） | 柱状图/折线图 | 视觉化更易理解 |
| 显示占比构成 | 饼图/环形图 | 直观展示部分与整体 |
| 对比多个类别 | 柱状图 | 易于比较大小 |
| 显示相关性 | 散点图 | 展示两个变量关系 |
| 显示分布 | 直方图/箱线图 | 展示数据分布特征 |
| 地理数据 | 地图 | 空间维度展示 |

## 决策流程图

```

  │
  ├─ 数据点 < 5？
  │   ├─ 是 → 使用表格
  │   └─ 否 ↓
  │
  ├─ 需要精确数值？
  │   ├─ 是 → 使用表格
  │   └─ 否 ↓
  │
  ├─ 显示趋势/时间变化？
  │   ├─ 是 → 使用折线图
  │   └─ 否 ↓
  │
  ├─ 显示占比/构成？
  │   ├─ 是 → 使用饼图
  │   └─ 否 ↓
  │

  │   ├─ 是 → 使用柱状图
  │   └─ 否 ↓
  │
  └─ 其他情况 → 使用表格
```

## 具体场景示例

### 场景1：销售数据

**数据**：12个月的销售额

```markdown
| 月份 | 销售额 |
|:----:|------:|
| 1月  | 100万  |
| 2月  | 120万  |
| ...  | ...    |
```

**建议**：
- 📊 **12个数据点 + 时间维度** → 强烈建议用**折线图**展示趋势
- 💡 表格适合作为图表的补充，显示精确数值

### 场景2：产品市场份额

**数据**：5个产品的市场份额占比

```markdown
| 产品 | 占比 |
|:----:|-----:|
| A    | 35%  |
| B    | 25%  |
| C    | 20%  |
| D    | 15%  |
| E    |  5%  |
```

**建议**：
- 📊 **占比数据** → 建议用**饼图**或**环形图**
- 💡 表格也很好，因为只有5个数据点

### 场景3：多维度产品对比

**数据**：3个产品的10项规格

```markdown
| 规格 | 产品A | 产品B | 产品C |
|:-----|:-----:|:-----:|:-----:|
| 价格 | ¥999  | ¥1299 | ¥899  |
| 重量 | 200g  | 180g  | 220g  |
| ...  | ...   | ...   | ...   |
```

**建议**：
- 📋 **多维度 + 需要精确值** → 使用**表格**
- ❌ 不建议用图表，文字信息太多

### 场景4：网站流量来源

**数据**：4个流量来源的访问量

```markdown
| 来源 | 访问量 | 占比 |
|:-----|------:|:----:|
| 搜索 | 5000  | 50%  |
| 直接 | 2500  | 25%  |
| 社交 | 1500  | 15%  |
| 推荐 | 1000  | 10%  |
```

**建议**：
- 📊 **占比数据** → 可以用**饼图**
- 📊 **访问量对比** → 也可以用**柱状图**
- 💡 两种都合适，根据场景选择

## 图表选择速查表

| 数据特征 | 推荐图表 | 备选 |
|:---------|:---------|:-----|
| 时间序列趋势 | 折线图 | 面积图 |
| 类别对比 | 柱状图 | 条形图 |
| 占比构成 | 饼图 | 环形图、堆叠柱状图 |
| 多变量关系 | 散点图 | 气泡图 |
| 数据分布 | 直方图 | 箱线图 |
| 排名对比 | 条形图 | 柱状图 |
| 部分与整体 | 饼图 | 树状图 |
| 多系列对比 | 分组柱状图 | 多折线图 |
| 地理分布 | 地图 | 气泡地图 |

## 混合使用建议

最佳实践是**表格 + 图表**结合使用：

```markdown
## 销售趋势分析

📊 [折线图：显示12个月销售趋势]

### 具体数据

| 月份 | 销售额 | 环比 |
|:----:|------:|:----:|
| 1月  | 100万  |  -   |
| 2月  | 120万  | +20% |
| ...  | ...    | ...  |

**关键发现**：
- 📈 整体呈上升趋势
- 🎯 6月达到峰值
```

这样既能看到**整体趋势**（图表），又能看到**精确数值**（表格）。

## 何时不建议图表

⚠️ **避免滥用图表**：

1. **数据点过少**（<3个） - 图表显得空洞
2. **数值差异微小** - 肉眼难以分辨
3. **需要精确数值** - 图表无法精确读数
4. **包含大量文本** - 图表不适合文本信息
5. **黑白打印** - 某些图表（如饼图）颜色信息丢失
